# README 中文本地化设计

## 目标

将项目根目录 `README.md` 的说明性文字改为简体中文，方便中文团队直接阅读和使用。

## 范围

- 翻译标题、段落、列表和说明性标签。
- 保持现有章节结构、链接目标和示例顺序。
- 保留命令、路径、文件名、包名、MCP 工具名、配置键、环境变量、JSON 字段和值的原样写法。

## 非目标

- 不改变 CLI、MCP、Git Hook、CI 或 Agent 集成行为。
- 不新增或删除功能说明。
- 不翻译代码块中的可复制命令与配置内容。

## 验证

通过 README 回归测试与人工检查，确认关键入口名称仍存在且链接和代码块保持有效。
